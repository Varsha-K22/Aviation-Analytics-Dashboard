# Aviation-Analytics-Dashboard
✈️ Aviation Analytics Dashboard
📌 Project Overview

The Aviation Analytics Dashboard is an interactive Power BI project developed to analyze airline operations, airport performance, flight delays, cancellations, and route efficiency using aviation data.

This dashboard provides operational insights through KPI-driven analytics, interactive visualizations, and time-based performance analysis to support data-driven decision-making in the aviation industry.

📊 Dashboard Pages
1️⃣ Executive Overview Dashboard

Provides a high-level summary of airline operations and flight performance.

Key Insights:
Total Flights Operated
On-Time Performance
Flight Cancellation Rate
Average Arrival & Departure Delay
Monthly Flight Trends
Flight Status Distribution
2️⃣ Route & Airport Analysis

Analyzes airport traffic and route performance across airlines.

Key Insights:
Busiest Flight Routes
Airport Traffic Analysis
Route Performance Comparison
Airport Delay Trends
Flight Volume by Route
3️⃣ Delay Analysis

Focused on understanding delay patterns and operational bottlenecks.

Key Insights:
Best Time to Fly
Delay Distribution Analysis
Delay Heatmap by Day & Hour
Delay Type Breakdown
Peak Delay Period Identification
4️⃣ Airline Performance

Compares airline operational efficiency and reliability.

Key Insights:
Average Delay by Airline
On-Time Performance Comparison
Cancellation Rate Analysis
Airline Operational Metrics
Delay Contribution by Airline
5️⃣ Airport Analysis

Evaluates airport operational performance and delay behavior.

Key Insights:
Best Performing Airports
Most Delayed Airports
Airport Reliability Analysis
Time-Based Airport Delay Insights
Airport Performance Comparison
